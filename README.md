# 生命棋局 · 红蓝对决（Conway Life Battle）

基于 [康威生命游戏](https://zh.wikipedia.org/wiki/康威生命游戏) 的红蓝双角色对战版：红蓝两方各有一个带 **白色光环** 的角色，每秒可部署一个己方细胞；敌方细胞一旦贴到角色，角色瞬间被消灭。

## 玩法

- 红蓝两方各有一个带 **白色光环** 的角色，**对角开局**（红左上、蓝右下）；
- 角色 **每秒可行动 1 次**：
  - **点击** 角色周围半径 2 内的空格 → 部署一个己方颜色的细胞；
  - **滑动** → 角色向该方向移动一格；
- 己方细胞遵循康威规则（B3/S23），演化诞生的细胞颜色取「三亲本多数」；
- 刚部署的细胞有约 **2 秒保护期**，不会被孤独淘汰；
- **战斗**：敌方细胞一旦贴到角色（周围 8 格），角色**瞬间被消灭**；两个角色相撞则同归于尽；
- 角色免疫康威规则，不会自然死亡；
- 三种模式：**双人同屏热座 / 人机（你是红方）/ 观战（AI 互斗）**。

## 运行（本地部署）

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080（手机浏览器全屏游玩）
```

也可用任意静态服务器托管，或开启 GitHub Pages（Settings → Pages → 选择 main 分支）。

## 编辑流程（代码以 GitHub 为准，本地仅部署）

本项目按「**在 GitHub 上编辑维护，本地仅部署运行**」的方式协作：

1. 在 GitHub 网页端修改代码并提交（或 clone 后 push）；
2. 本地部署目录执行 `git pull` 拉取最新代码；
3. 重启本地静态服务器即可生效。

## 目录结构（结构化编程）

```
├── index.html        页面骨架（HUD / 开始 / 结算界面）
├── css/style.css     移动端全屏适配（safe-area、防缩放、防滚动）
├── js/
│   ├── lib/p5.min.js 开源绘图库 p5.js（LGPL，已本地化，无 CDN 依赖）
│   ├── config.js     全局常量（规则参数、颜色）
│   ├── grid.js       网格模型：细胞状态 + 康威 B3/S23 演化
│   ├── player.js     玩家（角色）：冷却、部署半径
│   ├── game.js       游戏主逻辑：行动、战斗判定、胜负
│   ├── ai.js         简单 AI：贴脸击杀 / 推进部署 / 安全移动
│   ├── renderer.js   渲染：网格、细胞、白色光环、范围与冷却指示
│   └── main.js       入口：p5 实例、触摸/鼠标输入、UI 接线
├── test.js           核心逻辑冒烟测试（node test.js）
└── README.md
```

## 技术说明

- **开源工具**：p5.js（LGPL，随仓库本地化，离线可用）、GitHub 托管、gh CLI；
- **零构建、零依赖安装**：原生 HTML/CSS/JS + p5.js；
- **移动端全屏适配**：`viewport-fit=cover` + safe-area-inset、`touch-action:none` 防滚动缩放、devicePixelRatio 适配、手势操作（点击部署 / 滑动移动）；
- 逻辑层（Grid/Player/Game/AI）与渲染层（Renderer）分离，便于测试与扩展。
